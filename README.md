> landlord

The boss is the landlord: the one who owns the building and collects a cut of everything you make. It is funny at once because every worker knows the rent metaphor, and it is true because this Boss literally claims the prizes the agent's work wins — the hand that gives the work at midnight takes the win. It takes a surprising angle — nobody's first word for a boss is the person who takes the rent — and it travels anywhere: a kitchen, a warehouse or an office all have one.

## Run

```sh
node main.ts
```

Writes the word exactly, with no trailing newline, to `<MAKEFUN_OUTPUT_DIR or /output>/entry.txt`, mode 0644. Node 22.18 or later, standard library only, no network.
